# S3 试运营（10,000 条/月）— 运营计划

> **For agentic workers:** 本阶段无代码开发，是运营/验证清单。执行时按 checklist 逐项确认，不涉及 TDD。

**Goal:** 在真实生产节奏下（10,000 条/月）校准质量、成本、人工指标，为 30,000 条/月容量验证铺路。

**性质:** 运营阶段。无代码 task，全部为运营指标采集与达标判定。

**Spec:** `docs/superpowers/specs/2026-08-13-产能验证平台-design.md`

**前置条件:** S2 完成（6 人配置结论明确，Q6 已采集）。

---

## 目标

- 扩大到 Q6 对应配置的团队规模
- 测绿黄红真实比例、人工分钟数、重做率、成本
- 建立黄金样本库与回归评测（对应 spec FR-AI-005）
- 完善发布渠道接口（若含发布，对应 REQ-C05）

## 运营 checklist

- [ ] 团队按 Q6 结论配置到位（若 S2 结论是"需扩到 9-12 人"，按扩编执行）
- [ ] 黄金样本库建立：保存代表性通过/不通过案例
- [ ] 回归评测跑通：模型/规则变更前回归测试基线
- [ ] 发布渠道接口确认（若含发布）
- [ ] 成本看板上线：文本/搜索/图片/OCR/存储/重试成本分项统计

## 关键指标门槛（对应 spec §12.2，需求文档 §12.2）

| 指标 | 门槛 |
|---|---|
| 绿色内容比例 | ≥ 85% |
| 黄色平均人工处理 | ≤ 3 分钟/条 |
| 红色内容比例 | ≤ 3% |
| OCR 关键字段一致率 | ≥ 99.9% |
| 交付结构一次通过率 | ≥ 99.5% |
| 人工队列等待 | 满足客户确认 SLA |

## 退出条件

- [ ] 上述所有指标达标
- [ ] 质量与人工指标稳定（连续观测，无回退）

> 达标后进入 S4（容量验证）。
