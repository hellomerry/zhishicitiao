# S1 MVP 三人验证 — Q3 采集 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3 人并行跑 300-1,000 条，采集稳定合格产能 Q3，作为进入 S2（Temporal 迁移）与推算月产 10 万条的硬依据。

**Architecture:** 无代码开发。本阶段在 S0 建好的轻量栈平台上执行验证操作，产出的是真实产能数据而非软件。核心是采集 Q3（3 人稳定合格产能/天）与每专业域单条审核耗时（P50/P95）。

**Tech Stack:** 复用 S0 全部栈。本阶段无需新增依赖。

**Spec:** `docs/superpowers/specs/2026-08-13-产能验证平台-design.md`

**本阶段性质:** 验证操作清单（非代码）。仅含一个说明性 task（Task 22 暂停闸点）+ 完整验证操作步骤。

**前置条件:** S0 完成（轻量栈平台可运行，单人已跑通 30-50 条）。

**出口:** 稳定 Q3 + 仪器精度达标 → 进入 S2。

---

## 全局约束

- **一条口径**: 1 篇正文（400-700 字）+ 6 张图（1 封面 + 5 内页），不含发布
- **批次会签**: 绿色 85% 走批次 + 20% 抽检（固定机制，不作为变量）
- **模型供应商**: 1-2 家（合同/合规确认后定具体名单）
- **部署**: 客户本地（验证平台），模型 API 走公网（V-C03 客户独立确认）
- **三阶段团队**: 1 人 → 3 人 → 6 人（本阶段为 3 人）
- **核心埋点表**: `node_events` + `review_sessions` 实时聚合
- **降级不能伪造成功**: 任何降级路径必须留 `degraded=true`
- **异常值剔除**: 单条耗时 < 5 秒或 > 60 分钟不计入 P50/P95
- **独占锁**: 30 秒无心跳即挂起，连续 90 分钟无心跳自动挂起

## S1 验证操作清单（无代码，checklist）

### 团队配置

| 人员 | 角色 | 验证重点 |
|---|---|---|
| 审核员 A | 文案与事实审核 | 单条审核时间、事实问题率 |
| 审核员 B | 图片与版权审核 | 图片审核时间、返工率 |
| 审核员 C | 合规与交付审核 | 最终签发时间、拦截率 |

三人并行处理各自队列，非串行传递。

### 验证步骤（按顺序）

- [ ] **流程调通 50-100 条**：三角色确认工作台信息充分、责任清晰、问题易定位
- [ ] **小批验证 300-500 条**：修复系统问题，建立初始操作习惯
- [ ] **单日压力测试**：3 人全速 8 小时，测极限产能
- [ ] **稳定性测试**：连续 3-5 个工作日，测稳定合格产能

### 采集指标（全部从看板导出）

- [ ] Q3（3 人稳定合格产能/天）中位数
- [ ] 每专业域单条审核耗时 P50 / P95
- [ ] 绿色 / 黄色 / 红色比例分布
- [ ] 首次通过率（目标 ~85%）
- [ ] 人工触达率、返工率及平均返工次数
- [ ] 单任务包 / 单正文 / 单图片 / 单 OCR 成本 CNY
- [ ] 队列最大积压量、失败类型 Top-N
- [ ] 仪器精度报告：`time_inconsistency_flag`、`anomaly_rate`、抽检对账偏差

### 关键口径

- 第一天含学习磨合，**不作为正式测算依据**
- 最终使用连续 3-5 天的**中位数或较保守平均值**
- 产能分级：极限产能 / 稳定产能 / 合格产能，**用于推算的是稳定合格产能**

### 退出条件（进入 S2 的硬闸点）

- [ ] Q3 已稳定（连续 3-5 天，波动 < 5%）
- [ ] 仪器精度报告 `time_inconsistency_flag` < 1%
- [ ] 抽检对账偏差 < 5%
- [ ] 双盲对账偏差 < 10%
- [ ] 模型成本中位数已测出
- [ ] 绿色/黄色/红色比例稳定（波动 < 5%）
- [ ] 队列不持续增长

> 全部满足后，与项目方 review Q3 与模型成本数据，**才进入 S2（Temporal 迁移）**。禁止在 Q3 未稳定前启动 S2。
