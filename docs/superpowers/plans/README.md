## 关键闸点提醒

1. **S1 出口是硬闸点**：Q3 未稳定前，禁止启动 S2。Temporal Activity 的超时/补偿参数依赖真实数据，瞎填会产生伪精度。
2. **S0 和 S2 是有代码的阶段**，用 subagent-driven-development 或 executing-plans 执行。S1/S3/S4/S5 是清单，人工执行。
3. 每阶段文件都保留 `> **For agentic workers:**` 提示行，executor 按提示选择执行方式。
