## 二、已拍板的决策（只需知会，无需再议）

以下决策已通过四层工程评审（eng + CEO + design + Codex 双模型），作为既成事实：

| 决策 | 内容 |
|---|---|
| 一条口径 | 1 篇正文（400-700 字）+ 6 张图（1 封面 + 5 内页），不含发布 |
| 审核口径 | 批次会签 = 审核完成（绿色抽 20%，非人工逐条） |
| 产能目标 | Q3（3人）≥ 2,840 条/天 → 反推需 6 人；Q6（6人）≥ 4,545 条/天 → 覆盖月产 10 万 |
| 抽检比例 | 20% 固定 |
| 技术栈 | 两段式：轻量 asyncio（S0/S1）→ Temporal（S2） |
| 停止条件 | go/no-go 门槛：绿率 < 40% / 单条 > 15 分钟 / 事实错误 > 1% 即暂停转向 |
| 模型供应商 | 收敛到 1-2 家（名单待 V-C02 确认） |
| 部署 | 客户本地（验证平台），模型 API 走公网 |

---

## 三、验证目标（背景）

用 3 人 + 轻量验证平台跑出真实数据，回答月产 10 万条需要多少人、什么岗位、多少模型算力、什么成本。三阶段团队递进：1 人跑通 → 3 人协作 → 6 人实测。
